# Mini Bot — اپلیکیشن اندروید

پوسته بومی و سبک اندروید برای پنل کاربران Mini Bot.

## امکانات
- ورود با نام کاربری/رمز (سشن ذخیره می‌شود؛ دفعه بعد بدون ورود)
- همه امکانات ربات: داشبورد، فیش‌ها، پلن‌ها، قابلیت‌ها، تنظیمات
- آپلود عکس رسید (خرید پلن) و آواتار مستقیم از گوشی
- کش پایین‌بکش و تازه‌سازی (Pull to Refresh)
- لینک‌های واتساپ (پشتیبانی: +255 617 029 838) مستقیم در واتساپ باز می‌شوند
- دانلود فیش‌ها در پوشه Downloads
- صفحه اسپلش و حالت آفلاین با دکمه تلاش دوباره
- کاملاً هماهنگ با برند Mini Bot (تم تیره سبز)

## ساخت APK
هر push روی برنچ `main` باعث ساخت خودکار APK با GitHub Actions می‌شود.

دانلود مستقیم (همیشه آخرین نسخه):
```
https://github.com/minibot-af/minibot-android/releases/latest/download/MiniBot.apk
```
(همین لینک روی سایت Mini Bot دکمه «دانلود اپلیکیشن» است)

یا از تب **Actions** آخرین build موفق را انتخاب کن و فایل `MiniBot-APK` را دانلود کن.

برای انتشار نسخه جدید فقط یک تگ بزن (APK خودکار به Release اضافه می‌شود):
```bash
git tag v1.1 && git push origin v1.1
```

ساخت دستی (محلی):
```bash
gradle assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## آدرس پنل
`https://web.minibot.online` — اگر روزی دامنه عوض شد، فقط `PANEL_HOST` در `MainActivity.kt` را تغییر بده.

## معماری
Kotlin + WebView بومی + Material 3 — بدون فریمورک اضافه، حجم APK کمتر از ۳ مگابایت.
